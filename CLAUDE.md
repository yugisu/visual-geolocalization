# CLAUDE

When working with Python, invoke the relevant /astral:<skill> for uv, ty, and ruff to ensure best practices are followed.

When working with Marimo, please use marimo related skills. To use marimo, use `uv run marimo`.

.env file contains important env variables that reference to datasets, checkpoints, and contain API keys. Please don't forget to use `python-dotenv` inside marimo notebooks or top-level scripts.

Noteboks in the notebooks/ folder should be standalone Marimo Sandbox notebooks (docs page: https://docs.marimo.io/guides/package_management/notebooks_in_projects/).
